# 🚀 AllConvert — Конвертер файлов прямо в браузере

> Конвертируйте видео, аудио, изображения и документы на 100% локально. Без загрузки на сервер, очередей и отслеживания файлов.

👉 **Попробовать:** [https://allconvert.ru/](https://allconvert.ru/)

[English](README.md) | [Русский](README.ru.md)

---

AllConvert — это веб-приложение для обработки медиафайлов и документов прямо в вашем браузере с использованием **WebAssembly**, **WebCodecs** и нативных Browser APIs. 

Обычные онлайн-конвертеры заставляют отправлять личные файлы на чужие сервера, выстраивают в очереди и ограничивают размер файлов. AllConvert выполняет всю работу **локально на вашем устройстве**, обеспечивая полную приватность и экономию трафика.

## ✨ Основные возможности

- 🔒 **100% Приватность и локальная обработка:** Ваши файлы **НИКОГДА** не покидают устройство. Все процессы декодирования и кодирования происходят в оперативной памяти браузера. Вы можете отключить интернет сразу после загрузки страницы.
- ⚡ **Аппаратное ускорение:** Использование стандарта **WebCodecs** позволяет задействовать мощности вашей видеокарты для быстрой конвертации видео (где поддерживается браузером).
- 🚫 **Без серверов и регистраций:** Никаких личных кабинетов, подписок и искусственных ограничений по размеру файлов (лимит упирается только в объем ОЗУ вашего устройства).
- 📦 **Пакетная конвертация:** Загружайте пачку файлов, выбирайте нужные форматы и скачивайте результат одним ZIP-архивом.

## 📂 Поддерживаемые форматы

| Категория | Форматы |
| :--- | :--- |
| **Видео** | MP4, WebM, MOV, MKV, AVI, GIF |
| **Аудио** | MP3, WAV, AAC, FLAC, OGG, M4A, OPUS *(Быстрое извлечение звука из видео)* |
| **Изображения** | PNG, JPG/JPEG, WebP, AVIF, HEIC (iPhone), SVG, ICO, BMP |
| **Документы** | PDF, DOCX, XLSX, CSV, TXT, JSON, XML, Markdown *(Тестовый режим)* |

> ⚠️ **Обратите внимание:** Конвертация документов (PDF/DOCX) через WebAssembly находится в процессе активной доработки. В сложных файлах с нестандартными шрифтами или версткой могут возникать искажения.
